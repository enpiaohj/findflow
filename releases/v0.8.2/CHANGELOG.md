# FindFlow v0.8.2

发布日期：2026-10-10

> 本版本恢复应用内的「检查更新」：从这一版起可以在应用里一键升级，不必再手动下载安装包。

## Added
- 应用内更新：设置 → 关于 新增「软件更新」，菜单 帮助 → 检查更新。只在点击时访问 GitHub 读取更新清单（不做后台自动检查）；发现新版本后显示更新说明，确认后下载（带进度）、用内置公钥校验签名并安装，安装时应用自动关闭、完成后重新打开。
- 更新清单 `latest.json` 为 NSIS 与 MSI 各提供一条（新增脚本 `scripts/make-latest-json.mjs`），MSI 安装包也加上更新签名：此前清单只有指向 NSIS 的通用条目，用 MSI 安装的用户更新后会并存两份。

## Changed
- 「关于」页、README 与 SECURITY 的隐私说明更新为：仅有两种联网请求（可选的自然语言搜索、手动检查更新），都由用户主动发起。

## Known Issues
- 应用内更新的「下载 → 安装 → 重启」全流程未做实机验证（需要从低版本升级到高版本才能走通，且不能在开发机上安装）；已验证的是：更新清单匿名可取、两种安装包的签名能通过应用内置公钥校验、被篡改的文件会被判定无效。首次真实验证要等下一个版本发布。
- v0.8.1 及更早版本没有更新入口，需要手动下载安装一次本版本。
- MSI 方式的应用内更新会调用系统的 `msiexec`，可能出现管理员确认（UAC），未实测。
- 安装界面中文化与卸载列表名称仍未做实机安装验证；安装器窗口标题、开始菜单与桌面快捷方式仍为 `FindFlow`，不带版本号。
- 数据库迁移 v6、搜索提速在真实数据上的表现、网络共享并行读目录的提速，仍未在真实环境验证（同 v0.8.1）。
