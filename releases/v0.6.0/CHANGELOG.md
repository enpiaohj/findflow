# FindFlow v0.6.0

发布日期：2026-09-28

> 本版本聚焦设置体系重组与常驻体验：设置页按功能分类、新增系统托盘与开机自启、搜索历史与搜索栏交互打磨。

## Added
- 系统托盘：左键呼出主窗口；右键菜单提供「显示 FindFlow / 退出」。关闭按钮与失焦仍只隐藏窗口，退出统一由托盘菜单承担。
- 常规设置新增「显示托盘图标」开关：关闭后托盘区不再显示图标，即时生效且重启持久化；仍可用全局快捷键呼出窗口。常规页新增「退出 FindFlow」按钮，隐藏托盘后仍可完全退出进程。
- 新增「开机自动启动」：登录 Windows 后静默启动到托盘，不弹出主窗口。
- 搜索历史：按 Enter 或窗口隐藏时记录搜索词（与最近一条相同不重复，上限 50 条）；搜索框聚焦且无输入词时下拉展示，每项悬停可删除，支持一键清空；可在「隐私与安全」页关闭或清空。
- 新增「空搜索时隐藏结果」设置：开启后空搜索且无筛选时不显示启动列表与排序按钮，界面保持空白。
- 「关于」页：产品定位、版本号（实时读取）、源码仓库链接与隐私数据说明。

## Changed
- 设置页导航重组为「设置」「功能」两组：「设置」含常规 / 搜索 / 索引 / 文件与内容 / 外观 / 快捷键 / 隐私与安全 / 高级 / 关于；「功能」含空间分析 / 批量处理 / 任务 / 收藏与标签。原「索引」页拆分——启动列表设置归入「搜索」，索引内容与 OCR 归入「文件与内容」，索引诊断归入「高级」，「任务」页只保留任务。
- 「外观与快捷键」页拆分为外观 / 快捷键 / 窗口 / 启动卡片组（后续并入常规与独立快捷键页）。
- 搜索历史由输入时自动弹出改为搜索框内下拉箭头点击展开，输入关键词时自动收起。
- 搜索栏新增清除文本按钮，一键清空输入。
- 索引统计移至主窗口底部状态栏常驻显示。
- 导航「更新」改为「关于」。

## Fixed
- 索引内容模式空搜索仅列出索引根目录第一层（此前会列出全部层级），符合资源管理器式浏览预期；关键词搜索仍覆盖全部索引位置。
- 打开设置时启动列表卡片的状态闪现：读取设置完成前显示「正在读取」占位，不再闪现默认「索引内容」高亮。

## Removed
- 设置页「检查更新 / 下载并安装更新」入口：私有仓库下载端点不可用，自动更新暂不可用，「关于」页仅保留当前版本号显示。

## Known Issues
- 仓库为 Private，GitHub Releases 的匿名下载端点对自动更新检查（`latest.json`）可能返回 404，自动更新机制暂不可用；手动下载安装包不受影响。
