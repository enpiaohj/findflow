# FindFlow v0.5.0

发布日期：2026-09-28

> 启动列表模式：空搜索时可选择"索引内容"或"大文件"两种浏览方式，关键词搜索始终覆盖全部索引位置。

## Added
- 设置「索引与搜索」新增「启动列表」：默认「索引内容」模式，空搜索时列出所选索引位置下的全部内容并按名称排序；可切换为「大文件」模式，跨全部索引位置按大小降序显示（即此前版本的默认行为）。
- 配置多个索引位置时，可在设置中指定「索引内容」模式下的默认位置；该位置被停用或移除后自动回退为第一个启用位置。
- 搜索窗内没有任何启用的索引位置时，显示明确提示与「添加索引范围」入口，不再显示为"没有匹配的结果"。

## Changed
- 关键词搜索始终覆盖全部索引位置、默认按相关度排序；清空关键词后恢复设置中配置的启动列表模式。搜索窗内不再提供位置筛选下拉，位置只在设置页配置。

## Known Issues
- 仓库为 Private，GitHub Releases 的匿名下载端点对自动更新检查（`latest.json`）可能返回 404，自动更新机制暂不可用；手动下载安装包不受影响。
