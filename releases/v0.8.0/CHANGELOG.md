# FindFlow v0.8.0

发布日期：2026-10-10

> 本版本新增菜单栏、预览窗格与「直接输入路径」，统一了界面设计令牌并修复索引范围开关不生效的问题；仓库以 MIT 许可证发布。

## Added
- 菜单栏（文件 / 编辑 / 视图 / 搜索 / 工具 / 帮助）：点击或 `Alt+字母` 打开，悬停切换，↑↓←→ / Enter / Esc 键盘操作；文件菜单作用于当前选中项，工具 / 帮助可直达设置各页。
- 预览窗格（默认关闭）：筛选栏按钮或 `Alt+P` 开关；右侧常驻预览选中项并显示类型、大小、修改时间、路径与打开 / 定位 / 复制路径；拖拽分隔条调整宽度并记住，双击恢复默认；开启后列表隐藏重复的路径与操作列。
- 搜索框直接输入绝对路径（盘符或 UNC，可带引号）：列出该目录内容，回车直接打开该路径；方向键选过列表项后回车打开所选项；路径不存在时给出提示。
- 名称中的命中词高亮；空搜索且隐藏结果时显示可点击的搜索写法引导。
- 搜索菜单新增「仅搜索所选项所在文件夹」「清除文件夹限定」及 `path:` 语法示例。
- 许可证：MIT（`LICENSE`）；`THIRD-PARTY-NOTICES.md` 列出第三方组件许可证。

## Changed
- 界面：补全设计令牌（间距、字号、圆角、动效、浮层表面），统一搜索框聚焦光圈、选中行强调条、浮层样式；深色模式浮层改用更亮表面；适配系统「减少动效」。
- 对比度：调整浅色三级文字、深色强调色与状态色，文字对比度达到 4.5:1。
- 大图标：无缩略图时占位按文件类型着色；链接走主题强调色；元信息分隔改为细竖线；管理窗导航分组可折叠。
- 右键菜单：去掉多余的文件名标题；「复制文件」置顶；文件夹使用对应文案。
- 查询较慢时旧结果变淡而不清空，避免闪动。
- `path:` 写绝对路径时按目录边界匹配（不再误中 `D:\Temp2`），支持 `path:"D:\My Docs"`；`-path:` 同理。
- 空搜索点击筛选按钮时跨全部启用的索引位置查找，默认按修改时间。
- 打开不存在的路径时给出「路径不存在」提示，不再交给系统弹窗。
- 仓库公开前准备：重写历史（作者统一为 GitHub noreply 地址），内部设计文档不再跟踪，README / SECURITY 更新。

## Fixed
- 关闭索引范围后，其文件仍出现在搜索结果与「索引 N 条」里；现关闭即不参与搜索与计数，设置页统计只算启用范围，范围行显示「已关闭，不参与搜索」，重新启用时自动补一次校准。
- 空搜索点击筛选按钮时，结果被限制在默认位置根目录第一层（「图片」「文档」等常为空）。
- 从设置返回搜索窗后「索引 N 条」不刷新。
- 「减少动效」规则曾给所有元素制造极短过渡，改为直接取消。

## Known Issues
- 网络共享（`\\IP`）并行读目录的提速效果仍未在真实共享上实测。
- 菜单栏、预览窗格、路径输入等新功能未在真实应用中逐项点击确认（仅做了构建、单元测试与浏览器渲染验证）。
- 全量 `cargo test` 偶发 `searchindex` 临时文件写入 PermissionDenied（疑似杀毒软件占用，非功能缺陷），重跑通过。
- 输入路径只列出已被索引的目录内容；不支持路径补全与 `%VAR%` 环境变量写法。
