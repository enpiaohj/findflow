# FindFlow v0.8.1

发布日期：2026-10-10

> 本版本聚焦「搜索提速、索引自愈、安装包中文化」：点类型筛选与通配符查询从上百毫秒降到个位数毫秒；索引写入遇到杀毒软件干扰后自动恢复；安装界面改为简体中文。

## Changed
- 搜索性能：没有关键词的筛选查询（点「文档」「图片」等按钮、`*.pdf`、`ext:` / `type:` 等）改为沿排序索引边走边筛、凑够条数即停。85 万条数据实测（每次取 200 条）：「文档」约 371ms → 8.6ms，「图片」约 123ms → 3.9ms，`*.pdf` 130ms → 2.0ms。该路径设 25ms 时间预算，超时自动退回原有做法。
- 命中数：统计限时 20ms，来不及时先显示「命中 200+ 项」，后台算完再更新为精确数字（如「图片 + 最近 7 天」）。
- 排序在并列时次序固定（追加文件编号），同一查询的结果顺序稳定。
- 数据库迁移 v6：名称索引改为不分大小写（原索引排序规则与界面排序不一致，一直用不上），按名称浏览不再全表排序；升级时自动执行，百万行约 1 秒。
- 安装包：NSIS 与 MSI 的安装界面改为简体中文；「设置 → 应用」卸载列表里的名称带版本号（如 `FindFlow v0.8.1`），覆盖升级时自动更新。
- 文档：README 重写为完整的使用说明（下载与安装、搜索语法、快捷键、索引说明、性能基准、常见问题、目录结构），并更正「搜索词不落盘」的不准确表述（搜索历史保存在本机，可关闭或清空）；`SECURITY.md` 补充破坏性操作防护、安装包完整性与签名现状；`CLAUDE.md` 更新仓库可见性、技术栈、架构要点与发布流程；`AGENTS.md` 改为指向 `CLAUDE.md`；根目录 `CHANGELOG.md` 补上缺失的 v0.6.0 条目；`THIRD-PARTY-NOTICES.md` 按当前依赖重新生成。

## Fixed
- 索引写入器遇到 I/O 错误（典型：杀毒软件瞬时占用新建的索引文件，`PermissionDenied`）后会永久失效，之后新增 / 改名的文件一直搜不到，直到重启应用；现自动重建写入器并重放未提交的变更。
- 列表查询会丢弃出错的行，查询被中断时可能把不完整的结果当成完整结果返回；现改为上抛错误。
- README 中默认快捷键写成了 `Alt+Space`，实际为 `Alt+Q`。

## Known Issues
- 安装界面中文化与卸载列表名称未做实机安装验证（仅验证了打包脚本与安装包内的属性）；安装器窗口标题、开始菜单与桌面快捷方式仍为 `FindFlow`，不带版本号。
- 数据库迁移 v6 只在测试库与基准库上运行过，未在真实索引库上验证。
- 搜索提速的基准数据其修改时间为均匀分布；真实数据中某类文件集中在很久以前时，快路径可能超时退回原有速度（最坏多 25ms）。
- 网络共享（`\\IP`）并行读目录的提速效果仍未在真实共享上实测；菜单栏、预览窗格等功能未在真实应用中逐项点击确认。
- 输入路径只列出已被索引的目录内容；不支持路径补全与 `%VAR%` 环境变量写法。
