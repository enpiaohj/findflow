# FindFlow v0.7.1

发布日期：2026-10-10

> 本版本聚焦「匹配机制与全文检索更准确、网络共享索引更快更可见、右键菜单可键盘操作」。

## Changed
- 搜索：正文关键词按中文分词后要求全部命中，不再因其中一个词出现就命中。
- 搜索：文件名通配符（`*` / `?`）与普通关键词中的 `%`、`_`、`\` 按字面匹配（LIKE 转义），`*.ext` 直接走扩展名索引。
- 右键菜单：按「打开 / 位置 / 操作」分三组；支持 ↑↓ 循环切换并默认聚焦第一项；文件夹不再显示「打开方式…」；悬停与键盘焦点样式一致。
- 网络共享（UNC）索引：不再逐文件取 NTFS 稳定标识（每个文件一次网络往返）、不再预先统计总数（避免整棵目录树走两遍）；改为 4 个线程并行读取目录，条目处理与写库仍串行。
- 网络共享进度：每秒显示当前位置与已遍历数；等待服务器响应时显示「等待网络响应」。

## Fixed
- 网络共享不可达或无权限时，扫描曾以「完成，0 项」结束；现直接标记失败并写明原因。

## Known Issues
- 并行读取目录与跳过文件标识的提速效果未在真实 `\IP` 共享上实测；已有网络范围需「重建索引」后才不再写入文件标识。
