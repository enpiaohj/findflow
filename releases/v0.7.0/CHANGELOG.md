# FindFlow v0.7.0

发布日期：2026-10-10

> 本版本聚焦「搜索正确性、破坏性操作安全、索引可靠性」：筛选与命中数更准确，删除与整理满足产品底线（一次性令牌 + 稳定 ID 校验 + 逐项结果），索引事件不再因提交失败丢失，并补全网络共享、通配符搜索与状态栏体验。

## Added
- 搜索：文件名通配符（`*` 任意多字符、`?` 单字符），如 `*.pdf`、`报告*.docx`；`-type:图片` 按文件类型排除（与按文件名排除分开）。
- 索引：支持 UNC 网络共享路径（`\\服务器\共享`）作为索引范围；网络范围不做实时监听。
- 索引：自动定期校准（默认每天一次，可在「常规」关闭），补上实时监听遗漏；失败的范围按周期节流，不会每轮重试。
- 内容：自动提取正文（默认关闭，可在「常规」开启）；正文提取按 `file_id` 游标连续推进，单次任务可覆盖全库；开发与构建目录（`node_modules`、`target`、`dist` 等）不进正文索引。
- 存储：更换存储位置迁移成功后清理旧库；检测到旧数据目录冗余时，在「索引」页提示并可一键清理（保留 `llm.key` 与日志）。
- 结果列表：紧凑模式可拖拽调整列宽并持久化。
- 状态栏（搜索窗底部）：常驻显示选中项完整路径（过长从左侧省略，悬停显示可换行的完整路径）、大小与修改时间，并保留 `↑↓ 选择`、`Esc 清空 / 关闭` 提示；空搜索时显示全库「索引 N 条」。
- 批量处理：执行后保留逐项结果（成功 / 跳过 / 失败及原因）。

## Changed
- 筛选栏计数：带关键词或筛选时显示「命中 N 项」，空搜索浏览显示「共 N 项」，数字带千分位；状态栏「索引 N 条」始终表示索引总量。
- 「文档」筛选改为一组类型（Word、Excel、PDF、纯文本），不再漏掉表格与 PDF；需要单一类型时用 `type:doc` / `type:sheet`。
- 删除确认令牌改为系统 CSRNG 生成的 256 位随机值，绑定具体目标，一次性消费；删除请求带稳定 `fileId`，执行前与当前路径双重校验。
- 智能整理执行改为后端按参数重新生成计划，前端不能再注入任意路径；整理令牌绑定来源目录、规则与目标目录；源与目标均不得落在受保护目录。
- 搜索结果右键「移至回收站」增加确认对话框。
- 启动：主窗口在首屏加载完成后再显示，`index.html` 内联首屏背景色，消除启动白闪。
- 空结果提示区分「加载中」「当前筛选下没有结果」「没有匹配的结果」；「添加索引范围」按钮仅在没有索引位置时出现。
- 缩略图缓存超限时只淘汰最旧的约 1/4，不再整体清空，滚动时不再反复闪烁。

## Fixed
- 命中数：有查询条件时「共 N 项」曾一律返回索引总数（搜出 7 条却显示约 95 万），现为真实命中数。
- 带类型 / 扩展名 / 大小等过滤时，全文候选先按相关度截断再过滤，命中被白白丢掉；现放宽候选上限。
- 「在资源管理器中定位」：路径含逗号时被拆成两段而静默打开「文档」目录；改用系统 Shell API `SHOpenFolderAndSelectItems`，文件不存在时给出明确提示。
- 重命名目录后子树文件在库里仍保留旧路径（搜索命中后打开 / 定位指向不存在的位置）；现整体替换前缀。
- 「在 VS Code 打开」失败时曾一律提示成功；现等待命令结束并按退出码判断。
- 索引可靠性：outbox 事件在提交成功之前不再删除；提交失败（杀毒软件瞬时占用、磁盘满）时事件保留，进程崩溃后启动时自动重放，避免数据库与索引静默不一致。
- 受保护目录判断先展开 8.3 短名（如 `C:\PROGRA~1`），堵住短名绕过。
- 音频 / 视频 / Office / 图片 / 压缩包等扩展名映射补全（数据库迁移 v3、v5 就地修正旧记录的 `kind`，无需重建索引）；`.ts` / `.mts` 有意不归视频。
- 空搜索浏览按「范围 + 父目录」建复合索引（迁移 v4），实测 92 万行下由约 260 ms 降至亚毫秒。
- 状态栏在空结果时字段消失、空搜索时跑到窗口上方、换行等布局问题。

## Known Issues
- 仓库为 Private，GitHub Releases 的匿名下载端点对自动更新检查（`latest.json`）可能返回 404，自动更新机制暂不可用；手动下载安装包不受影响。
- `batchops.rs` 中批量移动 / 重命名尚未接入与删除相同的一次性令牌与稳定 ID 校验，留待后续版本。
