# FindFlow v0.4.0

发布日期：2026-09-27

> 无响应根治 + 索引逻辑修正 + 界面深度改版（系统文件图标、缩略图、深色模式、新应用图标）。

### Fixed
- 扫描范围包含数据目录（如 `D:\`）时，数据库 / 索引 / 日志的写入被监听回灌入库，形成无限循环（单日 3.3 万次索引提交、48MB 日志）；扫描与监听现跳过应用数据目录。
- 定时校准每次把全部文件重写并重新入队（百万级文件时队列永远排不完、WAL 涨至近 300MB）；现只处理新增、改名或变化的条目。
- 索引文件 ID 字段未建倒排，删除一直静默失效，删除 / 重命名 / 重建后的旧文档残留并挤占搜索结果；更新时也未先删旧文档导致重复。索引格式升至 v3，首次启动自动重建。
- 监听删除时先删行再登记索引事件，导致索引删不掉；Windows 重命名（From / To 两个事件）未配对，旧文件名残留；监听不遵守排除规则与 `$RECYCLE.BIN` 等系统目录。
- 范围根下第一层目录未做排除判断、也未作为文件夹入库。
- 校准在任务取消或根目录不可访问（如移动硬盘拔出）时会把整个范围判定为已删除；多范围时定时校准只执行第一个范围。
- 打开文件后记录"最近打开"、重命名、批量重命名、导出诊断包时后台 panic 导致界面无响应；重新扫描 / 校准 / 重建 / 存储占用命令报错。
- 删除范围、重建范围不再在界面连接上执行百万行删除；诊断统计与范围计数改走独立统计连接并缓存，设置页打开时搜索不再卡顿。
- "保存规则并重扫"未触发重扫且会覆盖"包含隐藏文件"设置。
- 样式表中被截断的规则与整段重复内容（前端构建 CSS 警告）。

### Changed
- 不再进入符号链接 / 目录联接（与 Everything 默认行为一致，避免 pnpm/npm 链接导致的重复索引与循环），链接本身仍可搜索。
- 索引提交节奏：满 2 万条 / 5 秒 / 空闲 1 秒提交；批量读取与去重，百万级全量重建约 4 分钟。
- WAL 上限 64MB，空闲期自动截断；tantivy 日志降为 warn；Tantivy 写入线程低优先级，纯 ASCII 文件名跳过拼音字段。
- 搜索总数缓存 10 秒，按键输入不再每次全表计数。

### Added
- 文件图标改用 Windows 系统图标（与资源管理器一致），取不到时回退为带扩展名的矢量图标；大图标模式显示系统缩略图。
- 深色模式：跟随系统 / 浅色 / 深色，全部页面适配。
- 新应用图标「流光透镜」，16–40px 使用像素对齐的简化图。
- 结果列表列标题可点击排序；路径列仅显示所在目录并保留盘符与末级目录；舒适模式显示所在目录；右键菜单在点击位置弹出。
- 快速预览改为"内容 + 信息栏"两栏布局，方向键切换文件、Enter 打开。
- 管理窗导航图标、页面副标题、开关控件；任务列表中文状态与结果摘要；索引健康横幅按真实状态显示。

## Known Issues
- 升级后首次启动会因索引格式 v3 自动全量重建索引（百万级文件约 4 分钟），期间搜索结果可能不完整，重建完成后恢复。
- v0.3.0 发布时的 latest.json 缺少 signature 字段，v0.3.0 本身的自动更新元数据不完整；本版本 latest.json 已包含签名，v0.2.0 / v0.3.0 均可通过自动更新升级到本版本（未实机验证，见下）。
